# addo-hub-app
Distribuições do ADDO Hub, o programa de segundo cérebro. Este repositório contém somente código distribuível e pacotes do programa, sem notas ou dados dos usuários.

O [instalador estável](https://github.com/eduardoalves-star/addo-hub-app/releases/latest) usa atualização assinada.

A [prévia financeira 0.5.0-previa.1](https://github.com/eduardoalves-star/addo-hub-app/releases/tag/v0.5.0-previa.1) é um ZIP manual para Windows com o ADDO Hub 0.4.1 instalado. Organiza cartões, compras, faturas, saldos de referência, cobranças recorrentes e posições de investimentos por OFX/CSV ou cadastro manual. Os dados ficam no cofre pessoal cifrado local. Não inclui conexão automática com bancos ou operações financeiras.

Para usar, extraia o ZIP e abra `Abrir Financas.cmd`; para experimentar num cérebro separado, abra `Abrir demonstracao.cmd`. O guia completo está nos arquivos da prévia. Essa distribuição não substitui o instalador estável nem a atualização automática.
